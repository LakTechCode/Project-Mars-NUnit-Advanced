# Project Mars NUnit Framework

This repository contains an automated test framework developed using C# and NUnit, designed to support scalable and maintainable UI testing.

## Tech Stack
- C#
- NUnit
- Selenium WebDriver
- Page Object Model (POM) design pattern

## Testing Focus
- Automated regression and end-to-end test suites
- Reusable components and utilities for efficient test maintenance
- Structured layering to separate page objects, test logic, and helpers

## How to Run
Tests can be executed using NUnit in Visual Studio or via the command line using the `dotnet test` command.

This project was created during training with Industry Connect / MVP Studio to demonstrate building robust automation frameworks.
